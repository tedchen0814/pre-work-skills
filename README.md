# rdq-grilling-skills

一鍵安裝三個 Claude Code skill：

| Skill | 用途 |
|---|---|
| `/rdq` | 動工前的需求訪談（四象限法），產出一頁需求規格卡，確認後才執行 |
| `/grilling` | 對計畫或想法做決策樹式拷問，一輪一輪問到共識（上游：Matt Pocock） |
| `/deep-and-wide` | 把已定的任務、提示詞或日常目標做深（可選做廣），交付診斷與附外部判官的重寫提示詞，問過才執行（上游：weber-yuan） |

## 安裝

**Windows (PowerShell)**
```powershell
git clone https://github.com/tedchen0814/rdq-grilling-skills.git ; cd rdq-grilling-skills ; .\install.ps1
```

**macOS / Linux / Git Bash**
```bash
git clone https://github.com/tedchen0814/rdq-grilling-skills.git && cd rdq-grilling-skills && ./install.sh
```

一律安裝到 `~/.claude/skills/`（全域），腳本不提供專案層選項，也不接受參數。
重複執行會覆蓋舊版。安裝後重啟 Claude Code。

## 使用

- `/rdq` 或說「跑 RDQ」：先訪談，再出規格卡
- `/grilling` 或說「grill me」：被拷問你的方案
- `/deep-and-wide` 或說「把這個任務做深」「做深做廣」「頂尖專家版本」：先給四問診斷與重寫後提示詞

## 三個 skill 怎麼選

三者都在**動工前**介入、都要你確認才執行，但解決的是不同問題：

- **rdq**：「我要什麼」還沒說清楚
- **grilling**：「這個計畫的每個決定」站不站得住
- **deep-and-wide**：目標已定，「怎麼做到頂尖水準」

| | **rdq** | **grilling** | **deep-and-wide** |
|---|---|---|---|
| 適用時機 | 需求模糊，缺對象、時間或產出格式 | 已有計畫或決定，要挑出漏洞 | 目標已定，想做得更深、更有野心 |
| 核心問題 | 你真正要的是什麼？ | 每個決定都想清楚了嗎？ | 頂尖的人會怎麼做這件事？ |
| 問你幾次 | 硬上限：Lite 打擾 2 次，Full 打擾 3 次 | 不設上限，問到所有決定都定案 | 最多問 1 題，其餘標明假設後繼續 |
| 提問方式 | 四象限分工：只問你當場答得出來的；你沒想過的做成選單讓你勾，並標代價 | 依決定的先後關係一輪一輪問，每題附建議答案 | 幾乎不問，直接給診斷 |
| 事實由誰查 | 掃描專案檔案、CLAUDE.md、舊規格卡 | 自己派子代理查，只把決定留給你 | 先讀 1–3 個檔案，最多搜尋一兩次 |
| 產出 | 一頁「需求規格卡」（❓ 假設、❌ 排除項），可存檔 | 雙方的「共同理解」，沒有規定格式 | 診斷 ＋ 重寫後提示詞，附外部判官 J1、J2… 與通過條件 |
| 核心原則 | 訪談的成本要低於它省下的返工 | 不留任何沒說出口的假設 | 做深是提高方法與品質，不是增加交付物；不讓模型評判自己的產出 |
| 之後的動作 | 確認後交給下游 skill 或直接執行 | 確認雙方理解一致才動手 | 問你要執行、修改或只保留提示詞；執行時用判官一輪輪驗證 |

### 關鍵差異

1. **方向**：rdq 往內收斂，把模糊需求收成一份規格；deep-and-wide 往上、往深走，在不改目標的前提下提高方法、原始材料與驗證標準；grilling 往下展開，把計畫拆成決定樹，每個分支都要你拍板。
2. **打擾程度**：rdq 最省注意力，題數寫死；grilling 最耗時，適合重大、不可逆的決定；deep-and-wide 幾乎不打擾，直接拿出更好的方案給你看。
3. **「你可能沒想到的」處理方式相反**：rdq 列成選單、每條標代價、預設不勾，沒勾的寫進 ❌ 排除項；deep-and-wide 直接寫進重寫版，由你事後刪。
4. **驗證**：只有 deep-and-wide 會事先定好「用什麼證明結果是對的」（測試、預測驗證、外部標準、指定第三方），並明確排除模型自評。

### 串成一條流程

```
需求模糊 → rdq 收斂成規格卡
         → deep-and-wide 把規格做深，加上判官
         → （計畫重大、不可逆時）grilling 逐題壓力測試
         → 執行
```

deep-and-wide 本身的分工表也這樣劃分：「釐清問題」交給 rdq 這一類，「逐題追問」交給 grilling。

> **觸發重疊提醒**：「幫我想想還缺什麼」可能同時觸發 rdq 與 deep-and-wide。需求本身還沒講清楚 → 用 `/rdq`；需求清楚、想提高水準 → 用 `/deep-and-wide`。不確定時直接打 slash 指令指定。
